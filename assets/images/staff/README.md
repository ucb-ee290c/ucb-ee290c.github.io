# Staff photos

Drop staff headshots here and reference them by filename from the `image:`
field of a staff entry in `_data/<semester>.yml`:

```yaml
staff:
  - role: "Instructor"
    name: "Jane Doe"
    image: "jane-doe.jpg"
```

Square images work best; they are cropped to a circle at 84 px. Anyone
without an `image:` gets a lettered placeholder instead, so photos are
optional.
